# Frete.com

> Frete.com is the Brazilian road-freight technology group formed in January 2023 when
> CargoX merged with Fretebras and FretePago. It operates Latin America's largest
> freight-matching platform, connecting shippers and carriers with autonomous truck
> drivers, and layers credit, cargo insurance, document issuance, truck tracking and
> payment rails on top of that marketplace.

Generated by API Evangelist on 2026-08-16 from the public Frete.com surface. This is
NOT a document published by Frete.com — the group does not serve an llms.txt of its own
(https://www.frete.com/llms.txt returned 404 on 2026-08-16).

## API status

**Frete.com publishes no public API contract.** As of 2026-08-16:

- There is no developer portal. `https://developer.fretebras.com.br/` returns HTTP 301
  to `https://fretebras2.zendesk.com/hc/pt-br`, a customer help center.
- The historical API host `api.fretebras.com.br` no longer resolves (NXDOMAIN on
  1.1.1.1 and 8.8.8.8).
- No OpenAPI, Swagger, AsyncAPI, GraphQL SDL, MCP server, A2A agent card, security.txt,
  api-catalog or openid-configuration document was found on any group host.
- A Fretebras integration API does exist: TOTVS Protheus (SIGATMS / SIGAGFE) ships a
  Fretebras connector that authenticates with `POST /oauth/token` and calls versioned
  `v1/` resources for vehicle types, bodies, cargo species, price types and freight
  offers. That contract is reached through partner/ERP channels, not through a public
  reference, and API Evangelist has not captured it because no first-party published
  specification exists.
- No first-party API client library is published on npm, PyPI, RubyGems, crates.io,
  Packagist, Maven Central, NuGet or the Go module proxy.

If you are an agent looking for a callable Frete.com API: there is not one you can
discover and call without a commercial relationship.

## Brands

- [Fretebras](https://www.fretebras.com.br/): the freight marketplace — shippers and
  carriers post loads, autonomous truck drivers find return freight.
- [CargoX Brasil](https://cargox.com.br/): working-capital credit, cargo insurance,
  transport document issuance and truck tracking for trucking companies. Unrelated to
  the Slovenian blockchain bill-of-lading company at cargox.io.
- [FretePago](https://api.fretepago.com.br/): digital account and freight payment rails
  for drivers and fleets.
- Rotas Brasil: route mapping and national toll pricing, acquired by Frete.com.

## Notes for agents

Fretebras' terms of use (section 5.6) explicitly prohibit commercializing, copying,
sharing or reproducing driver, freight or user data from the platform to third parties,
with a stated penalty per improperly accessed record. Treat any scraped Fretebras load
or driver data as contractually off-limits.
